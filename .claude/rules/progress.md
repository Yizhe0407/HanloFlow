## 快速定位問題的方法

```bash
# 某句輸出不對，先確認哪個詞條命中
python3 app.py --trace "問題句子"

# 搜尋可能 shadow 的舊詞條
grep -n "關鍵字" data/lexicon_entries.jsonl | grep '"status":"active"'

# 確認目前最新 round
grep -o '"source":"curation:round[0-9]*' data/lexicon_entries.jsonl | grep -o 'round[0-9]*' | sort -t d -k 2 -n | tail -3
```
